# 🏎️ APEX CORSE - Piattaforma Gestionale v3.0 (Sistema Aggiornamenti In-App, PWA & Link Privato)

> **Web App Gestionale Ufficiale di APEX CORSE - Versione 3.0**  
> Include tutte le funzionalità della **v1.0** e della **v2.0** (Area Personale, Organigramma Ufficiale con Co-Leads side-by-side, Timeline Gantt con priorità, Gestione Squadra) più:
> - **Sistema di Aggiornamento Automatico In-App**: quando viene rilasciata una nuova versione online o sul link privato, a tutti i membri del team compare in cima all'interfaccia il banner:  
>   🔔 **"NUOVO AGGIORNAMENTO DISPONIBILE! [ ⚡ Aggiorna Ora ]"**
> - **Aggiornamento con 1 Click Senza Perdita Dati**: cliccando su *"Aggiorna Ora"*, l'interfaccia si ricarica all'ultima versione preservando tutte le password personali, le task salvate e i ruoli.
> - **Centro Aggiornamenti Dedicato**: accessibile dal menu *Gestione & Opzioni* ⚙️, per verificare la versione installata, controllare gli update remoti e testare la notifica con il pulsante `🧪 Simula Notifica Membri`.
> - **Supporto PWA & Installazione come App**: include `manifest.json` e `sw.js` (Service Worker), permettendo a ogni membro su PC o smartphone di installare l'app con l'icona ufficiale Apex Corse.
> - **Predisposizione Link Privato**: non è più necessario inviare file zip e cartelle; consulta la guida `COME_PUBBLICARE_LINK_PRIVATO.md` per pubblicarla online gratis in 30 secondi.

---

## 📂 File Inclusi nella v3.0:
- `index.html`: Web App completa v3.0 con modulo di aggiornamento integrato.
- `version.json`: File con la versione corrente e le note di rilascio lette dall'app.
- `manifest.json`: Configurazione per installazione su desktop e smartphone.
- `sw.js`: Service worker per rilevamento background e cache offline.
- `apex_logo.png`: Logo ufficiale ad alta risoluzione.
- `Avvia_Web_App.bat`: Avvio rapido locale in 1 clic con il browser predefinito.
- `COME_PUBBLICARE_LINK_PRIVATO.md`: Guida pratica per avere il link privato online in 30 secondi.
